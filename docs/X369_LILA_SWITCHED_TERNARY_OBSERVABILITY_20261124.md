## 1. General exogenous switched affine theorem (F2d)

Finite set of modes m, available independently of state, full real domain R^n, T_m(h)=A_m h+b_m and O_m(h)=C_m h+d_m; all mode words admitted. Let V0=row span of all C_m and V_{k+1}=V_k + sum_m V_k A_m. Stabilizes after at most n-rank V0 strict steps. V_k is span of C_m A_{m_k}...A_{m_1} for words with <=k transitions. Affine offsets cancel. N=V_infty^perp is largest subspace contained in intersection ker C_m and invariant under every A_m. All-future equivalence iff h-h' in N (induction and finite separating row). A row basis B yields exact minimal continuous dimension rank B by linear section and invariance of domain. Factor C_m=G_m B, B A_m=F_m B; reduced recurrence z'=F_m z+B b_m, output G_m z+d_m. No reconstruction or path enumeration needed; row-space closure is sufficient and finite. Applies to arbitrary noncommuting/singular matrices. Arbitrary affine offsets allowed. Does not cover state-dependent guards by itself.

## 2. Guarded extension: exact maximal stable linear codec, not arbitrary nonlinear quotient

For each input x, state-dependent deterministic mode g_x(h) is included in the observation; each nonempty mode cell has affine T_{x,m},O_{x,m} (excluding mode label). Define G={v: g_x(h+t v)=g_x(h) for all x,h,t real}. G is a linear space by successive translation. N0=G intersect all ker C_{x,m} over nonempty cells. N_{k+1}=N0 intersect all A_{x,m}^{-1}N_k. Finite-dimensional descending iteration stabilizes at N*. For any full-domain linear codec with kernel N, guard/observation compatibility and successor-code stability iff N subset N0 and all A_{x,m}N subset N. Proof: necessity choose h in any nonempty cell; h+t v stays in cell for every real t, so affine differences force row and successor conditions. Sufficiency by direct substitution. Thus N* gives maximal stable linear compression, dimension n-dim N*. Finite collection of explicitly given rows and matrices yields algorithm; continuum inputs give a mathematical characterization not automatic effective extraction. Actual softmax, GELU, radial cap are not piecewise affine generally. Do not infer minimality among all nonlinear codecs, nor use guard normals of unreachable/redundant branches. Exogenous all-word result is stronger than guarded stable-linear result.

## 3. Source-legal untagged R4 with ternary weights and full behavioural injectivity

E=4, top_k=2, d divisible by 3, expert width >=2d, any H in R^(4d), coherent c2_c3_residual, all activations allowed, no probe overrides. Inspect models/history_orbit_moe.py and models/trialectic_wave_prior.py from #5 (original model blob unchanged). Zero baseline C2 router and expert biases. Residual unary and forward/reverse directed weights zero, self channel per triad 1; phase_x=rotate3(x)=R x. Then s_e=(Rx) dot h_e. Zero orientation weight, original nonzero z fallback first nonzero component sign: x nonzero ensures sign +/-1. Expert first layer reads +/-canon_h coordinates, second layer subtracts paired GELUs; ideal-real GELU(z)-GELU(-z)=z gives y_e=h_e after source sign multiplication. All trainable matrices entries in {-1,0,1}, including identity selected transitions preserving h (ignore x,y); zero biases, no cap. This is explicit ternary design with unit scale, NOT a claim that applying BitNet's absmean quantizer to these sparse matrices leaves them unchanged. Native activation quantization is not used. O=(output, ordered ids, signs, weights), T=full history. Initial histories arbitrary, no fixed tags. Identity transitions permit actual sequential probes without reset (one-step injectivity proof also holds for arbitrary transitions using reset queries).

For each coordinate l choose x=R^{-1}e_l and -x. Write z_e=(h_e)_l. Positive query selects two largest z; negative selects two smallest. For each query let signed scores s_i,s_j, weights a,b>0 with a+b=1, mu=(Rx)^T y=a s_i+b s_j, delta=log(a/b)=s_i-s_j. Invert s_i=mu+b delta, s_j=mu-a delta. Negate negative-query scores to recover original z. Any expert absent from both lists implies overlap between two size-two lists on four indices, so the second and third largest scores coincide: if strict gap the lists would be disjoint and exhaustive. The missing score lies between the two boundary scores, hence equals their common value. This is valid for any deterministic tie rule choosing valid top-k, including different tied orders, without requiring ties be resolved identically across +/- queries. Thus both queries recover every labelled z_e. Repeat for l=1..d: 2d labelled queries recover all 4d history coordinates. Hence full behavioural equivalence is equality on R^(4d); no continuous encoder of lower dimension (invariance of domain). For q-symbol scalar alphabet, at least q^(4d) codewords or ceil(4d log2 q) fixed-length bits. This is a state/storage bound only, not work lower bound. For E=2K generalize to K selected scores by s_i=mu+log w_i-sum_j w_j log w_j; tie argument identical. Observing weights and expert IDs is essential to this proof; result-only observer remains separate. Full domain arbitrary initial states, not assertion that every state reachable from original zero initialization or fitted checkpoint. Fixed model inference, not learning equivalence.

## 4. Ternary storage vs behavioural quotient, quantitative guard

Exact already-ternary integer dot sum = positive support sum - negative support sum. Signed int8 activation bound 128 gives |dot|<=128K for inner dimension K, sufficient signed int32 safety K<=floor((2^31-1)/128)=16777215 (separate scale/rounding). 2-bit +2 encoding maps -1,0,1 to 1,2,3; unused 0 invalid. Packing changes representation, not semantics of already ternary values. Quantizing arbitrary dense matrices can change exact rank in either direction; identity 2x2 absmean=.5 maps to .5I, erasing all its exact fixed directions under a direct naive use of upstream quantizer. Fixed-unit rounding diag(1,1,7/8) -> I creates extra fixed directions; dependent rows (.6,.4),(1.2,.8) -> (1,0),(1,1) increase row rank. Fixed-unit examples not claimed to be exact upstream absmean conversion. For affine quotient B, replacement A' preserves original reduced transition iff B A'=B A and B b'=B b, for same B and observer. Mere equality of ranks not enough. For selected relative logits errors, strict ordered decisions survive when each relevant pair gap exceeds bound on pairwise error. For x and weights quantized with W=alpha T, dequantization error <= ||W-Wq||*||x||+||Wq||*||x-xq|| in any compatible induced norm. Exact guard needs calibrated actual error; all-tie probe proof is mathematical, not robust to arbitrary perturbations. For selected inversion, log weights become ill-conditioned near zero, so bounded logit range and weight floor required for numeric F3. Source GELU rounding also separate. No claim of native bit identity or throughput.
