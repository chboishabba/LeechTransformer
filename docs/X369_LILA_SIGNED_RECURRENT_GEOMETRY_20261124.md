## G4e1. Exact signed C3 chart, original zero-score obstruction

Let V be a stack of ordered real triads, R simultaneous cyclic rotation of every triad. Canonical representative c(v)=lexicographic max{v,Rv,R²v}. Define sigma(v)=sign_lex(c(v)-c(-v)), i.e. +1 when c(v)>c(-v), -1 for reverse, 0 for equality. It is C3-invariant because rotating permutes the same orbit, and odd because negation swaps the two operands. Equality implies R^k v=-v for some k, hence applying three times gives v=-v, so v=0 over R. Thus sigma=0 iff v=0. This is a discontinuous chart, not a differentiable global section; for dim>=2 no continuous nonzero odd scalar sign on the connected punctured real space. Existing source first-nonzero fallback is odd but not C3-invariant: (1,-1,0) and Rv=(-1,0,1) have opposite fallback sign at learned score zero. With observed sign included, this is a genuine trace distinction even if outputs happen to agree. For a C3-invariant learned orientation score, use the new chart ONLY as an opt-in zero-score fallback to obtain full ideal-real C3 chart invariance. Do not silently change source semantics. Source fallback retained in exact adapter.

## G4e4. Nonlinear phase-to-DC generation and reverse no-go

For exact GELU G(t)=t Phi(t), G(t)+G(-t)=t erf(t/sqrt(2))>0 for t!=0. Thus pure phase triad (t,-t,0) has zero DC, but sum of its activated coordinates is strictly positive. This is intrinsic nonlinear phase-to-DC coupling even when every linear block preserves DC and phase separately. In the reverse direction, a stack of DC-only triads stays DC under all C3/S3 linear blocks with DC biases, coordinatewise GELU, scalar signs/weights, cap and inactive identity. Thus if both x and initial H are DC-only at every step, no rotating information can appear by this recurrence. Explicit DC->phase bridge, non-DC bias or non-DC input is necessary to escape under these assumptions. Zero mode is not disposable just because input is zero mean; retain it at each time-indexed stage unless a genuine downstream quotient proves sufficiency. No fitted-model or task claim.
